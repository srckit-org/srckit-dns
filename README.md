# srckit-dns

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Look up DNS records for any domain using Google's DNS-over-HTTPS API.

## Features

- **Lookup** — Query specific record types (A, AAAA, CNAME, MX, NS, TXT, SOA, CAA) with TTL display
- **All Records** — Query all record types at once for a complete DNS overview

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
